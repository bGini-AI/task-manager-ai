# מנהל המשימות – מערכת אישית חכמה עם סוכן AI

מערכת לניהול משימות בעברית (RTL): מרחבים עם צבע ותצוגה משלהם (קנבן / רשימת TODO / לוח שנה), דשבורד מרכזי, וסוכן AI בצ'אט שיכול לקרוא, להוסיף, לעדכן, למחוק ולסכם משימות.

## טכנולוגיה
- Next.js (App Router) + TypeScript + Tailwind CSS
- Postgres (`pg`) – הטבלאות נוצרות אוטומטית (`tm_spaces`, `tm_tasks`, `tm_settings`, `tm_agent_actions`)
- סוכן: OpenAI Chat Completions עם 5 כלים (`read_tasks`, `add_tasks`, `update_tasks`, `delete_tasks`, `summarize_tasks`)
- כניסה בסיסמה אחת (`APP_PASSWORD`) עם עוגיית session חתומה

## משתני סביבה
| משתנה | תיאור |
| --- | --- |
| `DATABASE_URL` | חיבור ל-Postgres |
| `OPENAI_API_KEY` | מפתח OpenAI |
| `APP_PASSWORD` | סיסמת הכניסה למערכת |
| `OPENAI_MODEL` | אופציונלי, ברירת מחדל `gpt-6-luna` (קידומת `openai/` מוסרת אוטומטית) |
| `SESSION_SECRET` | אופציונלי, סוד לחתימת העוגייה |

## הרצה מקומית
```bash
cp .env.example .env   # ולמלא את הערכים
npm install
npm run seed           # נתוני דוגמה (3 מרחבים, 16 משימות)
npm run dev
```

## התנהגות הסוכן
- בראש חלון הצ'אט מוצג על מה הסוכן עובד: מרחב מסוים או כל המרחבים. בתוך מרחב הוא נבחר אוטומטית, בדשבורד – כל המרחבים, וניתן לשנות בקליק.
- הבחירה נשלחת עם כל הודעה, והשרת מגביל את כל הכלים אליה.
- לפני פעולה על יותר מ-3 משימות או לפני מחיקה, הסוכן מציג כמה משימות ישתנו ומחכה ללחיצה על "מאשר" / "לא מאשר" (נאכף בשרת).
